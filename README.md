# For Real Academy

Static course-selling site (plain HTML/CSS/JS, no build step) using the For Real Tech design tokens.
Operated by For Real Tech LLC. Courses: web development and AI tools only.

Run locally: `python3 -m http.server 8792`

## Before applying to Polar
- `config.js`: prices are placeholders. Set real prices and paste each Polar checkout link into `checkout.full` / `checkout.split`.
- Installments: Polar has no fixed-length payment plan, so create the "3 monthly payments" product as a subscription and cancel it after the 3rd payment, or sell one-time only. Make the site text match what you set up.
- Set the real domain, add `og.png`, and confirm the legal pages (terms, privacy, refunds) match how you operate.
- Describe the business accurately in the Polar application, including any related businesses.
