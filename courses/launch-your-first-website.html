Launch Your First Website

Go from blank folder to a live, mobile-friendly website on your own domain. HTML, CSS, a little JavaScript, Git and free hosting.

LevelBeginner
Length6 modules · about 8 hours
FormatSelf-paced, recorded

What you'll learn

  • Structure pages with semantic HTML
  • Style responsive layouts with modern CSS
  • Add forms and simple interactivity
  • Version your work with Git and GitHub
  • Deploy and connect a custom domain

Curriculum

  1. Browser, editor and how the web works
  2. HTML: structure, text, links, images, forms
  3. CSS: layout, flexbox, grid, responsive design
  4. JavaScript basics: events, DOM, a small interactive feature
  5. Git and GitHub: commits, branches, publishing your code
  6. Deploy: free hosting, custom domain, HTTPS, going live

Who it's for

Anyone starting from zero: career changers, students, small-business owners who want their own site.

What you'll need

A computer (Windows, Mac or Linux) and internet access. No prior coding needed.

What you'll finish with

A live personal or small-business website you built and published.
